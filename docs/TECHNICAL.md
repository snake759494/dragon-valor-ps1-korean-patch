# 기술 문서

## 디스크 구성
| 파일 | 내용 |
| --- | --- |
| `SLPS_021.90`/`.91` | 실행 파일 (두 디스크 동일) |
| `BIN/OPENNING.BIN` | 타이틀·로드 오버레이. **고정 글꼴 페이지**(TIM, VRAM 704,256, 4bpp 256×256, 오프셋 `0xEFD0`)와 디스크 교체 안내 TIM |
| `BIN/MAP.BIN`, `BIN/ACTION.BIN` | 월드맵·필드 오버레이. 메모리 카드 메시지, 후계자 이름, 게임오버 문구 |
| `TITLE/DB_TITLE.TIP` | 타이틀 배경·로고, 설정 메뉴 텍스처 |
| `DATA.CDR` | 모든 스테이지 데이터. 섹터 정렬 컨테이너(`u32 개수, u32 오프셋[개수+1]`)의 묶음 |
| `MOVIE/MOVIE1.STR`/`MOVIE2.STR` | 오프닝 동영상 (STR v3, 304×224) |

## 텍스트 인코딩
16비트 리틀엔디안 글리프 코드입니다.

```
bit 0-4   행 (0~20)
bit 5-9   열 (0~20)
bit 10-13 글자 진행 폭(px)
bit 14    페이지 (0 = 고정 글꼴, 1 = 장면 글꼴)
```
특수 코드: `FFFF` 끝, `8000` 줄바꿈, `8888` 스크롤 줄바꿈, `3000` 전각 공백, `1800` 반각 공백, `90B2` 대사 시작, `98xx` 화자 이름, `88xx`·`A0Fx`·`FCCC` 연출·색 제어.

글자 하나는 12×12 칸이고 진행 폭이 코드에 들어 있어 가변폭이 가능합니다. 한글은 진행 폭 12로 넣었습니다.

## 글꼴
- 고정 글꼴(페이지 0): 기호·숫자·영문 줄은 유지하고, 가나·한자 칸 308개를 번역문 전체에서 가장 자주 쓰이는 한글 음절로 바꿨습니다. 메뉴·시스템 문자열은 이 페이지만 씁니다.
- 장면 글꼴(페이지 1): `DATA.CDR` 의 `TIM_CODE` 블록(VRAM 768,256)이 장면마다 바뀝니다. 각 대사 블록이 쓰는 페이지를 찾아(같은 컨테이너 → 가장 가까운 앞 페이지 → 참조 칸이 모두 채워진 가까운 페이지 순) 그 장면에 필요한 음절만 배치합니다. 최대 86자/441칸.
- 렌더링: 갈무리11을 12px(UPM 1200, 1px=100유닛) 원래 크기로 그려 확대·축소 없이 픽셀이 칸에 정확히 맞습니다. 잉크는 팔레트 0, 배경은 15(투명).

## 텍스트 삽입
- 대사 항목은 컨테이너 안의 개별 항목입니다. 항목을 새로 인코딩해 컨테이너를 다시 짜고, 원래 마지막 섹터의 여유 범위를 넘지 않게 했습니다(단위별 파일 표가 섹터 위치를 MSF로 고정하므로).
- 스크롤 문장은 화면 중앙(123px)을 기준으로 줄마다 다시 가운데 정렬합니다.
- 아이템·마법 설명 표: `u16 오프셋[n]` + 문자열(`8000` 끝). 스테이지마다 사본이 있어 모두 바꿨습니다.
- 게임오버 문구(`ACTION.BIN 0x2AE~`)는 `행<<5 | 열` 형식이라 따로 변환합니다.

## 그림 글자
- 지역명 TIM(VRAM 960,320 / 512,472, 4bpp 160×32): 위쪽 일본어 영역을 지우고 서울한강체로 다시 그림, 영문 부제는 유지
- 장 제목 카드: 각 장 배경 TIM(VRAM 576,0, 8bpp)의 왼쪽 128×80
- 월드맵 시트(VRAM 768,0): 장 제목·스테이지 목록·버튼
- 가계도(VRAM 384,0, 8bpp): 이름 상자를 마스크 대조로 찾아 갈무리11로 다시 그림
- 설정 메뉴: `DB_TITLE.TIP` 4bpp 텍스처의 글자 영역 좌표별 재작성

## 동영상
오프닝은 STR **v3**(DC를 MPEG-1처럼 차분 VLC로 부호화)입니다. v3 디코더·인코더를 만들어 원본 프레임을 비트 단위로 똑같이 재인코딩하는 것을 확인한 뒤, 로고 장면 115프레임에 글자를 합성했습니다. 프레임 크기가 원본을 넘지 않도록 글자 없는 매크로블록의 AC 계수를 잘라 냅니다. 프레임 끝 10비트 마커, 4바이트 정렬, 섹터 헤더의 MDEC 헤더 사본 규칙을 지킵니다.

## 섹터 기록
수정한 섹터는 Mode2 Form1 EDC/ECC를 다시 계산합니다(`tools/cdecc.py`).
